# TerraSeed — 절차적 지형 생성기

브라우저에서 실행하는 시드 기반 가상 세계 지도 프로토타입입니다. `mcseedmap.com/ko`의 시드 입력 → 세계 생성 → 지도 탐색 흐름을 참고했으며, 지형 생성 알고리즘과 렌더러는 독립 구현입니다.

## 실행

ES 모듈과 IndexedDB를 사용하므로 파일을 직접 여는 대신 로컬 정적 서버로 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 현재 구현

- 시드가 같으면 세계 크기, 대륙 배치, 바이옴이 동일하게 생성됩니다.
- 전체 면적은 1조 m² 주변의 로그정규형 분포로 결정됩니다. 1.5조 m² 부근의 세계는 0.7조 m² 부근보다 낮은 확률로 생성되도록 중심값과 분산을 설정했습니다.
- 지도는 전체를 메모리에 올리지 않고 256×256 래스터 청크로 스트리밍합니다.
- LOD(레벨 오브 디테일)에 따라 한 래스터 픽셀이 나타내는 지형 범위를 조절합니다. LOD 0에서 1 래스터 픽셀 = 1m입니다.
- 완료된 청크는 렌더 옵션(바이옴/나무/해안선), LOD, 시드, 월드 리비전별로 구분해 IndexedDB에 WebP 이미지로 저장하고 재사용합니다.
- 청크 렌더 중에는 흐림 오버레이를 잠시 사용합니다.
- 대륙/섬, 숲, 평야, 산, 언덕, 강, 호수, 바다, 늪, 툰드라, 사막을 생성합니다.
- 나무는 줄기와 다층 다각형 수관을 가진 작은 실루엣으로 렌더링합니다.
- 문명 시뮬레이션을 위한 `TerrainEventStore` API를 분리해 두었습니다.

## 좌표와 스케일

세계 좌표 단위는 미터입니다. LOD 0의 지형 샘플 간격은 1m입니다. 화면의 CSS 픽셀과 실제 지형 1m는 확대율에 따라 달라집니다. 세계 면적이 약 10¹²m²이므로 전체 세계를 한 번에 1m/px로 표시하는 것은 불가능하며, 축소 시에는 자동으로 저해상도 LOD 청크를 요청합니다.

## 모듈 구조

- `src/core/`: 시드, 노이즈, 세계 차원 및 지형 샘플링
- `src/render/`: 청크 래스터 생성 및 나무 렌더링
- `src/storage/`: IndexedDB 캐시 어댑터
- `src/simulation/`: 미래 지형 이벤트 저장 및 적용 인터페이스
- `src/main.js`: UI, 뷰포트, 스케줄링 조정

백엔드 이전 시 `ChunkStore`를 서버 API 어댑터로 교체하고, `core`의 순수 계산 함수를 Web Worker 또는 서버 작업 큐로 옮기는 것을 권장합니다.

## 다음 개발 단계

1. 청크 생성 Web Worker 풀과 우선순위 큐
2. 실제 하천망(고도 기반 유역/유량 계산)과 더 정교한 해안 지형
3. 청크별 버전 관리 및 시뮬레이션 변경분만 재렌더링
4. 서버 저장소와 사용자별 월드 메타데이터 API
5. 지도 내 지형 정보 조회, 좌표 복사, 바이옴 필터

## 참고

현재 버전은 절차적 지형의 기반을 검증하기 위한 프로토타입입니다. 하천은 시드 기반 곡선으로 근사하며, 수문학적 유역 분석이나 실제 지구의 기후 모델을 구현한 것은 아닙니다.
